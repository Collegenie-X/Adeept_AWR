## 🎯 Simple Car 소개

**simple_car**는 **ultra_simple_car.py를 핵심으로 하는 모듈형 자율주행차** 프로젝트입니다!

### ✨ 핵심 특징
- 🎮 **ultra_simple_car.py**: 모든 기능이 통합된 메인 프로그램
- 🧩 **모듈형 설계**: components/ 폴더의 기능별 서비스 클래스
- 🛣️ **적응형 라인 추적**: 4단계 지능형 회전 강도 자동 조절
- 🛡️ **스마트 장애물 회피**: 40cm 조기 감지 + 안정적 3단계 회피
- 🎛️ **실시간 제어**: 자율주행 중에도 즉시 설정 조절 가능
- 🔊/🔇 **센서 토글**: 상황에 맞는 초음파 센서 on/off 제어
- 📋 **종합 도움말**: h키로 모든 기능 즉시 확인 가능

### 🎯 프로젝트 목표
- **교육용**: 고등학생이 쉽게 이해할 수 있는 코드 구조
- **실습형**: 실제 하드웨어와 연동하여 바로 테스트 가능
- **확장형**: 새로운 기능을 쉽게 추가할 수 있는 모듈 구조

## 🤖 자율주행 및 장애물 인식 동작 원리

### 📊 자율주행 시스템 전체 동작 흐름

```
🚀 자율주행 시작 (Enter키)
     ↓
🔍 센서 데이터 읽기
     ├── 📏 라인 센서 (좌/중/우)
     └── 📡 초음파 센서 (거리)
     ↓
🧠 상황 판단 및 우선순위 결정
     ├── 1순위: 장애물 회피 (초음파 센서 ON시)
     ├── 2순위: 적응형 라인 추적
     └── 3순위: 안전 동작 (111 패턴 등)
     ↓
🚗 모터 제어 명령 실행
     ├── 전진 (기본 동작)
     ├── 좌/우 회전 (4단계 강도)
     └── 장애물 회피 시퀀스
     ↓
⏱️ 설정된 시간만큼 대기
     ↓
🔄 반복 (자율주행 종료시까지)
```

### 🛡️ 장애물 인식 및 회피 상세 동작

#### 1단계: 거리 감지 및 분류
```python
# components/autonomous_driver.py의 동작 원리

거리 측정 → 상황 분류:
├── 40cm 이상: "안전" (정상 주행)
├── 35-40cm: "조기감지" (속도 감소)
├── 25-35cm: "경고" (회피 준비)
└── 25cm 미만: "위험" (즉시 회피)
```

#### 2단계: 안정적 3단계 회피 시퀀스
```python
# manual_controller.py의 obstacle_avoid_left() 함수

🛑 1단계: 완전 정지 (0.1초)
   - 모든 모터 속도 0으로 설정
   - 안정적인 회전 준비
   
🔄 2단계: 제자리 좌회전
   - 좌 모터: +고속 회전
   - 우 모터: -고속 회전 (반대 방향)
   - 설정된 회전 시간만큼 지속
   
✅ 3단계: 전진 재개 (옵션)
   - forward_after=True인 경우만
   - 일정 시간 전진 후 라인 추적 복귀
```

### 🎯 적응형 라인 추적 시스템

#### 라인 센서 패턴 분석 및 대응
```python
# manual_controller.py의 analyze_line_position() 함수

센서 패턴 → 동작 결정:
├── "010": 중앙 직진 (미세조정: 0.08초)
├── "110": 약간 좌측 (약한 우회전: 0.12초)
├── "011": 약간 우측 (약한 좌회전: 0.12초)
├── "100": 많이 좌측 (보통 우회전: 0.18초)
├── "001": 많이 우측 (보통 좌회전: 0.18초)
├── "000": 라인 완전 이탈 (강한 탐색: 0.25초)
└── "111": 모든 센서 감지 (특별 처리)
```

#### 🚫 111 패턴 특별 처리 (신기능)
```python
# 모든 센서가 라인을 감지하는 복잡한 상황 처리

"111" 패턴 감지시:
🛑 1단계: 확실한 정지 (0.1초)
🔙 2단계: 후진 이동 (0.1초)  
↰ 3단계: 좌회전으로 라인 재진입
```

### 🔊/🔇 초음파 센서 토글 시스템

#### u키 동작 원리
```python
# config_service.py의 toggle_ultrasonic_sensor()

u키 입력 → 상태 변경:
├── 현재 ON → OFF로 변경
│   └── autonomous_driver.py에서 장애물 감지 건너뛰기
└── 현재 OFF → ON으로 변경
    └── autonomous_driver.py에서 장애물 감지 활성화
```

#### 성능 최적화 효과
- **센서 OFF**: 라인 추적만 수행 → 더 빠른 반응속도
- **센서 ON**: 라인 추적 + 장애물 회피 → 안전한 주행

### ⏱️ 실시간 회전 시간 조절 시스템

#### 3,4키 동작 원리
```python
# config_service.py의 adjust_turn_hold_time()

3키 (+0.05초):
├── 현재 시간에 0.05초 추가
├── 최대 0.5초까지 제한
└── 더 큰 회전 각도 달성

4키 (-0.05초):
├── 현재 시간에서 0.05초 감소
├── 최소 0.1초까지 제한
└── 더 작은 회전 각도로 빠른 복귀
```

#### 자율주행 중 실시간 적용
- 설정 변경 즉시 다음 회전부터 적용
- 트랙 특성에 맞는 최적화 가능
- 주행 중단 없이 미세 조정 가능
