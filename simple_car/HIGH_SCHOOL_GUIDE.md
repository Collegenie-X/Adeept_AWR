## 🎯 프로그램 소개

이 프로그램은 **고등학생도 쉽게 이해할 수 있도록** 만든 자율 주행차입니다!

### ✨ 주요 기능
- 🛣️ **라인 추적**: 검은 선을 따라갑니다
- 🛡️ **장애물 회피**: 앞의 장애물을 피합니다
- 🧠 **똑똑한 주행**: 두 기능을 합쳐서 안전하게 운전합니다
- 🎮 **수동 조종**: 키보드로 직접 조종할 수 있습니다

### 🔧 기술적 특징
- **모듈화**: 기능별로 파일을 나누어 이해하기 쉽게 구성
- **단순화**: 복잡한 수학이나 알고리즘 없이 간단한 if문만 사용
- **주석**: 모든 함수와 중요한 부분에 한글 설명 추가
- **테스트**: 각 기능을 안전하게 테스트할 수 있는 함수 제공

## 고성능 자율주행 시스템 완성! ⚡🚀

### 새 파일: `ultra_simple_car_fast_response.py`

#### **🚀 성능 개선 사항**:

### **⚡ 반응속도 대폭 향상**
✅ **의사결정 주기**: 0.2초 (기존 대비 **5배 빠름**)  
✅ **센서 읽기 주기**: 0.05초 (20Hz 고속 센싱)  
✅ **안전 거리**: 12cm (더 가까운 거리에서 빠른 반응)  

### **🧵 멀티스레드 아키텍처**
✅ **라인 센서 스레드**: 독립적인 라인 데이터 수집  
✅ **초음파 센서 스레드**: 병렬 거리 데이터 수집  
✅ **키보드 입력 스레드**: 논블로킹 실시간 제어  
✅ **메인 제어 스레드**: 0.2초마다 빠른 의사결정  

### **📊 센서 데이터 스무딩**
✅ **히스토리 버퍼**: 최근 3개 데이터로 노이즈 제거  
✅ **다수결 알고리즘**: 라인 센서 오작동 방지  
✅ **평균화 필터**: 초음파 센서 데이터 안정화  

### **⚙️ 실시간 성능 조절**
✅ **z,c 키**: 의사결정 주기 0.05초 단위 조절  
✅ **v,b 키**: 센서 읽기 주기 0.01초 단위 조절  
✅ **범위**: 0.05초~1.0초 (기존 대비 20배 세밀함)  

### **🧠 우선순위 기반 판단**
✅ **장애물 회피**: 최우선 (안전성)  
✅ **라인 추적**: 2순위 (미션 수행)  
✅ **복구 알고리즘**: 3순위 (오류 복구)  

#### **성능 비교표**:

| 기능 | 기존 버전 | 고성능 버전 | 개선도 |
|------|-----------|-------------|--------|
| 의사결정 주기 | 1.0초 | 0.2초 | **5배 빠름** |
| 센서 읽기 | 0.1초 | 0.05초 | **2배 빠름** |
| 센서 처리 | 단일스레드 | 멀티스레드 | **병렬 처리** |
| 노이즈 필터링 | 없음 | 스무딩 | **안정성 향상** |
| 반응속도 조절 | 없음 | 실시간 | **세밀한 제어** |

#### **실제 사용 시나리오**:

## ✅ **노란색 도로선 회피 주행 로직 완료**

### 🎯 **핵심 변경 사항**

**도로 환경 이해:**
- **도로**: 검정색 ⚫
- **도로선**: 노란색 🟡
- **목표**: 노란선을 피해서 검정 도로 위를 안전하게 주행

### 🔧 **수정된 센서 로직**

```python
# 센서 패턴 해석 (노란색 선 감지)
- HIGH(1): 노란선 감지 (밝은 색)
- LOW(0): 검정 도로 감지 (어두운 색)

# 주행 전략
safe_black_road    → ✅ 검정 도로 위 안전, 직진
yellow_center_danger → ⚠️ 노란선 밟음! 즉시 회피
yellow_left_line   → ↪️ 왼쪽 노란선 감지, 우측으로 회피
yellow_right_line  → ↩️ 오른쪽 노란선 감지, 좌측으로 회피
```

### 🛣️ **상세 주행 로직**

1. **안전 구간 (000 패턴)**
   - 모든 센서가 검정 도로 감지
   - 노란선 없음 = 도로 중앙
   - **동작**: 안전하게 직진

2. **중앙 위험 (010 패턴)**  
   - 중앙 센서만 노란선 감지
   - 차량이 노란선 위에 있음
   - **동작**: 즉시 검정 도로로 회피

3. **좌우 경계선 (100, 001 패턴)**
   - 왼쪽/오른쪽 노란선 감지
   - **동작**: 반대 방향으로 회피하여 검정 도로 중앙으로

4. **코너 구간 (110, 011 패턴)**
   - 노란선이 코너를 형성
   - **동작**: 강한 회전으로 안전한 검정 도로 구간 확보

5. **좁은 도로 (101 패턴)**
   - 양쪽에 노란선
   - **동작**: 속도 감소하여 신중하게 중앙 직진

6. **교차점 (111 패턴)**
   - 모든 센서에 노란선
   - **동작**: 최저 속도로 신중하게 직진

### 🎮 **사용법**

1. **프로그램 실행**
   ```bash
   python3 simple_car/ultra_simple_car.py
   ```

2. **디버깅**
   - `x` 키: 노란선 센서 상태 10초간 모니터링
   - `z` 키: 거리 센서 상태 확인

3. **자동 주행**
   - `s` + Enter: 노란선 회피 자동 주행 시작
   - `p` 키: 즉시 정지

### 💡 **주행 원리**

- **기본 원칙**: 노란선을 피해서 검정 도로 위를 주행
- **센서 해석**: HIGH = 노란선, LOW = 검정 도로
- **회피 전략**: 노란선 감지 즉시 검정 도로 쪽으로 회피
- **안전 우선**: 좁은 구간이나 교차점에서는 속도 감소

이제 자동차가 **노란색 도로선을 정확히 피해서 검정색 도로 위를 안전하게 주행**할 수 있습니다! 🚗🛣️
